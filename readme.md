# CineWorld

## Tema

CineWorld é um site desenvolvido com o tema filmes e séries, apresentando novidades, lançamentos, destaques do cinema e uma área de contato para interação com os usuários.

## Páginas do Projeto

### Home

Página inicial contendo:

* Menu de navegação responsivo
* Carrossel de destaques
* Apresentação do projeto
* Cards com informações e destaques

### Galeria

Página dedicada a:

* Novidades do cinema
* Próximos lançamentos
* Galeria de imagens
* Cards informativos sobre filmes e séries

### Contato

Página contendo:

* Formulário de contato
* Informações de contato fictícias
* Redes sociais fictícias
* Mapa incorporado
